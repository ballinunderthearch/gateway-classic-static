# Gateway Invitational Classic — public static archive

Preserves the approved entrance, nine-state interactive map and Illinois Headquarters from private application commit `9ca6614a17e1e1cb4300b39f7c1c286c3f1ae6fe`.

This separate repository contains public artwork and read-only browser code only. No private application history, credentials, sessions, database exports, registration, authentication, payments or backend APIs are included. Illinois teams are explicitly fictional placeholders; invitation requests are disabled while the project is paused.

Run locally with `python3 -m http.server 8003 --bind 127.0.0.1`. GitHub Pages serves the repository root. Publication is manual: do not push unapproved changes to the publishing branch. Artwork rights are reserved; no open-source license is granted.
